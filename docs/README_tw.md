## 專案簡介

MicoMusic 是以米可為角色主題、基於 MoeKoeMusic 獨立維護的音樂播放器。第一階段品牌初始化已完成，Liquid Glass 尚待驗證與開發。目前未發佈 MicoMusic 安裝包。應用採用獨立標識、資料目錄與 micomusic:// 協定，不自動遷移原版資料；分享暫時只複製推薦文字或邀請碼。保留 GPL-2.0 與上游來源說明。
