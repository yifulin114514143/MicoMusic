## 프로젝트 소개

MicoMusic은 MoeKoeMusic을 기반으로 독립 개발하는 Mico 테마 음악 플레이어입니다. 1단계 브랜드 변경을 완료했으며 Liquid Glass는 이후 검증과 개발 대상입니다. MicoMusic 설치 패키지는 아직 공개하지 않았습니다. 독립 앱 식별자, 데이터 폴더 및 micomusic:// 프로토콜을 사용하며 원본 앱 데이터를 자동 이전하지 않습니다. 공유 기능은 추천 문구 또는 초대 코드를 복사합니다. GPL-2.0 라이선스와 원본 출처를 유지합니다.
