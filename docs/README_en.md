中文优先：安装、功能状态与开发说明以 [中文 README](../README.md) 为准。本页是 MicoMusic 简介，不提供原版安装包作为 MicoMusic 下载。

## Project summary

MicoMusic is an independently maintained music player based on MoeKoeMusic, with an anime visual theme built around Mico. Phase 1 branding is complete. Liquid Glass is planned and has not been delivered. No MicoMusic installers have been released. The desktop app uses its own identity, data directory and micomusic:// scheme; it does not migrate the original app data automatically. Sharing currently copies recommendation text or invitation codes. GPL-2.0 and upstream attribution are retained.
