# MicoMusic

中文优先：安装、功能状态与开发说明以 [中文 README](../README.md) 为准。本页是 MicoMusic 简介，不提供原版安装包作为 MicoMusic 下载。

## プロジェクト概要

MicoMusic は MoeKoeMusic を基に独立して開発されている、Mico をテーマにした音楽プレーヤーです。第1段階のブランド変更は完了しました。Liquid Glass は今後の検証・開発対象です。MicoMusic のインストーラーはまだ公開されていません。専用のアプリ識別子、データフォルダー、micomusic:// を使用し、元のアプリのデータは自動移行しません。共有は紹介文または招待コードのコピーのみです。GPL-2.0 と上流の帰属情報を保持しています。
