## О проекте

MicoMusic — независимо разрабатываемый музыкальный проигрыватель на основе MoeKoeMusic с визуальной темой персонажа Mico. Первый этап изменения бренда завершён. Liquid Glass предстоит проверить и разработать. Установочные пакеты MicoMusic пока не опубликованы. Приложение использует отдельные идентификатор, каталог данных и протокол micomusic://, без автоматического переноса данных оригинала. Функция обмена копирует текст рекомендации или код приглашения.
