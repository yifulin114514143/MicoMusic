## 冲突处理与兼容修正

`package.json`、`package-lock.json` 保留 MicoMusic 的应用名称、项目主页、更新仓库、应用协议、独立标识和插件打包配置，只接收版本变化。根依赖与开发依赖未变化，沿用已有依赖安装；新版 API 使用其自身 `pnpm-lock.yaml` 完成冻结安装。

`electron/appServices.js` 接收 `paintWhenInitiallyHidden` 修复，同时保留 MicoMusic 等待内置主题就绪后显示首屏的逻辑。最小化启动仍不自动显示窗口，普通启动继续等待首屏主题。

上游 `Library.vue` 直接解构 Pinia 的 `listenTime`，会使分钟数停留在初始值。本次改为在计算属性中读取 store。回归测试先复现 `0 !== 120`，修正后验证 0 → 120 → 180 分钟的连续更新。

原生验收新增 `/user/grade/info` 的隔离响应，覆盖新增 store 初始化请求；输出保存到本次日期目录。诊断期间曾尝试聚焦测试窗口及关闭观测弹窗后台节流，最终移除这些临时诊断改动。
