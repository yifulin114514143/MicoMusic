# 流体及光学材质实现记录

本插件的 JavaScript 与 GLSL 独立编写。研究材料包括项目内的沉浸播放器重构指南，以及 [liquid-glass-webgl](https://github.com/martin65536/liquid-glass-webgl) 在 `b4e0a6910443cea7cdd4b1bfcf7b2394e0a15e48` 的公开结构与光学操作次序。没有复制其 Apache-2.0 源文件、函数文本、截图或素材，也没有移植 LyricsBlossom 闭源实现。不能将指南中推演的数值称作 Apple 官方参数。

流体将四色提色与真实封面的空间颜色结合，在两级噪声域扭曲中持续融合，噪声时间采用 `u_time * .18`。48×48 像素量化选取主要、次要、亮、暗四色，忽略透明像素；彩色封面的强调色排除 RGB 最大最小通道差不超过 0.18 的浅色文字和灰边，黑白封面仍使用实际灰阶。另外将同一真实封面降采样为32×32纹理，在旋转、扭曲的UV中宽范围九点采样，保留空间色彩而消除可辨识的封面细节。临时降采样画布上传后立即清空。首次绘制前完成提色时直接使用封面色；如果此前已绘制回退色，或随后切换封面，则以1500ms smoothstep插值引入新颜色和空间纹理。跨域不允许读取、坏图或纹理上传失败会明确记录 `paletteStatus` / `coverSceneError`，转入静态CSS回退；更换为可读取的封面可以恢复。不能将回退宣称为成功封面提色。

WebGL1一个上下文、一个场景framebuffer，隐藏的GL画布提供两个可见2D输出。先绘制流体，将其复制到背景画布；再按封面真实DOMRect、圆角和 `object-fit: cover` 裁切，将实际封面纹理合入场景。玻璃从该场景采样，透明输出复制到前景玻璃画布。流体使用独立纹理，封面未加载前使用完整的1×1占位纹理，避免对当前framebuffer附件自采样。背景与玻璃跟随Hero的真实透明度，玻璃输出不接收指针事件。

玻璃形状使用圆角距离场。RGB通道分别按1.43、1.45、1.48的折射率进行Snell折射，Schlick反射控制曲面边缘亮度；这些是本实现的参数。十二个Gaussian加权Vogel圆盘采样生成磨砂，折射后的红蓝通道也经过同一模糊及亮度压缩，不再把清晰封面细节混回文字背后。按钮使用轻薄表面；菜单从小圆展开时逐渐增加模糊、亮度压缩和柔软投影，成为适于白字阅读的regular材质。边缘距离及法线控制曲率高光，指针影响局部高光。更多按钮和菜单在opening/closing的短暂阶段通过smooth minimum连成薄颈；其他时刻是独立表面。

菜单根据封面、歌词和按钮的实际DOMRect占用中间空白区，必要时平滑移开专辑；窄窗口暂时淡出歌词释放空间。首次展开先让小圆进入空白区再增大，文字延迟160ms、在220ms内显现，完整展开前不可交互。菜单中途反转从实际矩阵续接；菜单展开途中退出播放器时冻结专辑父节点的当前位置，再执行封面Hero，保证返回实测小封面。深色主题只在该插件视图存在时撤回宿主html的全局brightness/multiply，并局部纠正range黑底；关闭视图或插件后自动恢复宿主主题。

间奏点作为真实歌词布局行插入前后句之间，只采用已提供的句末和下一句起点，不虚构结束时间。当前插件自定义最短间奏为4000ms；这不是Apple官方参数。短句间隔不显示点。圆点大小和透明度随真实音频进度变化，暂停后静止。歌词、封面、表单、音频控制始终是宿主DOM，未创建音频元素或音频频谱输入。

GPU DPR上限1.5；流体场景每CSS像素一采样，输出玻璃边缘以capped DPR抗锯齿。连续流动和有界过渡均以60fps为目标；真实帧率另由原生运行测量。播放暂停、减少动效、低模糊时不维持持续RAF；可见时指针/尺寸变化允许单帧刷新，切封面和菜单展开允许有界过渡。低模糊继续跟随有界菜单/Hero几何，但背景时间保持静止、磨砂设为零，过渡结束即停止帧。离屏或原生隐藏时停止RAF、删除GPU对象并清空三个画布的backing store，恢复可见时重建。GPU丢失时停止循环、显示静态CSS，并在浏览器context restore后重建。禁用/卸载撤回三个画布、GPU资源、监听、观察器与进行中的封面读取，最后主动释放自有GL context。

诊断：背景节点 `data-mico-fluid-state` 是 JSON；销毁前 `document` 发 `mico-fluid-diagnostics` CustomEvent，detail 为同样的 JSON 字符串。`coverSceneStatus`、`coverSceneDraws` 和 `outputCanvases` 记录封面场景上传、实际合成次数及可见输出数量。计数来自真实创建/删除调用和 draw，不代替 GPU 硬件利用率。`resources` 显示当前活资源，`allocations/deletions` 可核对反复开关清理。人工对照与运行记录另外验收；本实现不宣称所有 Apple / LyricsBlossom 光学细节已完全相同。
